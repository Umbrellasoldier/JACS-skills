# v0.6 绘图工具分工与混合插画规则验证

日期：2026-09-17。范围：技能指引、参考文件、用途判断和发布包装。

## 改动与依据

新增 [imagegen 制作流程](../../skills/jacs-figure/references/imagegen-workflow.md)，
从[技能入口](../../skills/jacs-figure/SKILL.md)、化学绘图、输入约定、QA 和投稿审阅按需进入。
提供正文概念插画、封面两类提示词模板，以及分层合成、生成来源记录和最终尺寸检查。
不把 imagegen 设为数据图或安装流程的必需依赖。

本轮重新查看 [ACS 官方 AI 政策](https://researcher-resources.acs.org/publish/aipolicy)
的 Graphics 部分；页面标注更新日为 2024-12-13，核查日为 2026-09-17。
此前建议优先用 imagegen 制作 TOC 不适合作为正式投稿路线，已在
[共享政策快照](../../skills/jacs-shared/references/graphics-policy.md#ai-generated-artwork)
及各入口纠正。用途、科学含义和素材来源分别判断，不能由导出格式推断是否适用。

这些新增规则属于工具与制作流程设计，不是新一轮文献蒸馏结果。
原有 50 篇／199 幅文献图的证据范围不变。

## 需求路由复核

以下为维护代理对最终指引的逐项阅读复核，不是独立代理前向测试、实际图像生成结果，
也不用于计算成功率。

| 需求情景 | 指引给出的处理 | 核对位置 |
|---|---|---|
| “判断哪些图应该用 imagegen” | 给选择和理由；不因咨询而执行生成 | 技能入口及新参考文件的用途判断 |
| “把现有箱线图或热图改成淡亮色” | 修改原绘图源，保留数据映射；不把数据图交给生成式编辑 | 意义与目的地表、现有图库分工 |
| “美化已有六框 SVG 流程图” | 优先原生矢量修改；按科学内容选择必要插图 | 化学绘图的 Workflows 段落 |
| “制作带图注的正文方法概念图” | 可生成非定量插画；结构、数据、文字及流程关系由独立来源图层承担 | 分层制作流程与正文提示词模板 |
| “用我的 XYZ 展示过渡态” | 按坐标渲染并保留测量来源；不以生成插画代替几何 | 意义与目的地表 |
| “没有坐标，补一张真实 TS 图” | 记录缺少坐标，使用明确的概念表达或继续不依赖坐标的部分；不虚构计算结果 | 内容确定步骤与科学审阅 |
| “制作 ACS TOC，放一个 AI 背景” | 采用无生成图像的 TOC 制作路线；不以背景、改名或描摹绕过来源区分 | 共享政策、TOC 指引与来源记录 |
| “设计论文封面” | 可进行概念生成；按封面目的处理尺寸、科学表达和相关披露 | 封面提示词模板及共享政策 |
| “当前环境没有 imagegen” | 说明工具限制，继续可完成的规划或精确绘图；不冒称生成、不暗换 API | 可选工具能力段落 |
| “混合插画的 PDF 检查通过了” | 仍需检查栅格素材含义、最终尺寸有效分辨率和图注；保留真实提示词和输出 | 来源记录、最终审阅与 QA |

## 限制

本轮没有调用图像生成工具，没有生成或改绘图库图像，也没有执行独立前向行为评测。
因此不宣称生成模型稳定遵守约束、成图更美观或新插画达到投稿水平。
全部 17 幅示例仍沿用 v0.5；它们的实际视觉复核见
[v0.5 报告](../figure-v5/REPORT.md)。新增提示词是可复用指引，不是已执行的图像生成记录。

渲染器不识别 AI 素材来源，也不自动执行政策检查；新规则由使用技能时的用途判断和
实际成图审阅落实。旧文献研究、历史盲评与历史安装快照保留原样，不记作本版新增验证。
