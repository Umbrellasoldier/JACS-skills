# JACS polishing

Edit at the requested depth. A local grammar change needs the source sentence and affected
facts, not a new manuscript plan. Preserve established terminology and earlier user choices.

Read [editing decisions](references/editing.md) when translation, compression, or structural
edits require more than a local correction. For energy, TS validation, selectivity, or model
evaluation language, read the relevant part of
[chemistry semantics](../jacs-shared/references/chemistry-semantics.md).
For author-directed emphasis, less report-like prose, or learning from paired revisions, read
[argument and evidence](../jacs-shared/references/argument-and-evidence.md). Preserve the requested
scope: a stronger tone does not by itself request a new analysis, figure or manuscript plan.
Consult [journal policy](../jacs-shared/references/journal-policy.md) for actual formatting
questions, and [pilot findings](../jacs-shared/references/pilot-findings.md) only when empirical
style calibration would help. The pilot is not a universal JACS house style.

First identify the sentence's scientific assertion, supporting evidence, and conditions.
Then repair syntax, information order, ambiguity, and repetition. Preserve chemical names,
stereochemistry, symbols, comparison direction, uncertainty, units, and denominators.
Converting a unit or correcting an author-identified error is allowed when the transformation
is checked and made clear; literal numeric identity is not the only test of factual fidelity.

Make supported advantages explicit. Replace repeated hedges, implementation narration and
generic self-disqualifying endings with precise results and their scientific consequences.
Embed essential selection, population and comparison conditions concisely in the claim;
retain outcomes that change its meaning. Explain the design's role at the strength supported
by the evidence. An observed advantage can be stated confidently without claiming isolated causality.

Do not turn a weak or indirect result into a stronger claim to make the prose fluent.
In particular, do not exchange ΔE‡ and ΔG‡, replace a retrospective best-case result with
a deployment prediction, or describe an unperformed IRC as completed. If the supplied text
conflicts with the supplied evidence, correct within the supported meaning and flag the
specific discrepancy. Missing evidence should remain missing.

Return the edited text in the requested format. Explain only consequential changes unless a
full edit rationale is requested. When asked for text only, supply text only if a supported
edit is possible. Escalate to argument reconstruction only when that is the requested task
or when a local edit cannot repair the problem; do not silently change the task.
