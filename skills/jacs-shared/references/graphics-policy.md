# JACS graphics policy snapshot

Journal: Journal of the American Chemical Society, CODEN `jacsat`.
Checked 2026-09-17 against [JACS author guidelines](https://researcher-resources.acs.org/publish/author_guidelines?coden=jacsat)
(updated 2026-08-27) and the linked [TOC guide](https://pubsapp.acs.org/paragonplus/submission/toc_abstract_graphics_guidelines.pdf)
(updated 2024-02-28). Recheck for a submission; do not import Nature requirements.

| Applicability | Snapshot |
|---|---|
| Main graphics | Single-column width ≤240 pt; double-column width 300–504 pt |
| Main graphics | Total height including caption ≤660 pt; reserve caption space |
| Main graphics | Lettering ≥4.5 pt and lines ≥0.5 pt at publication size; readability still matters |
| Raster artwork | Minimum 1200 dpi for black-and-white line art, 600 for grayscale, 300 for color |
| Figures | Self-contained numbered caption; artwork and text use consistent symbols |
| Chemical structures | Use a chemical drawing program; Figure, Chart and Scheme serve different roles |
| TOC | Maximum 3.25 × 1.75 in; sans-serif type preferably 8 pt, at least 6 pt |
| TOC exports | Color TIF 300 dpi; black-and-white TIF 1200 dpi; EPS RGB with fonts embedded/outlined |
| TOC purpose | Original unpublished artwork, a concise impression of the chemistry; not a dense results panel |

The TOC guide also specifies authorship/originality and placement requirements; consult it
when preparing the submission package. AI artwork is a distinct route requiring current
ACS policy review, not automatically cleared by passing these technical checks.

The supplied 7–8 pt plot text, open axes, palettes and 1.5 pt alignment tolerance are project
defaults, not additional ACS mandates. SI page layout is task-dependent. Accessible encoding
uses labels/markers as well as color. Actual figure height plus manuscript caption must be
checked together; a standalone figure file cannot certify the combined height.
